Privacy Policy

Last updated: 5 June 2026

Overview

The Dundee Recovery Map is a static web application. It does not collect, store, or process any personal information. This policy explains what limited data may be handled and by whom.

Data

No personal data is collected directly. There are no user accounts, no login, no forms that submit personal information, and no analytics tracking on this site.

Cookies

This site does not set any cookies. No tracking cookies, session cookies, or preference cookies are used.

Hosting

This site is hosted via GitHub Pages. GitHub may log basic server access data (such as IP addresses) as part of their standard hosting infrastructure. Please refer to GitHub's Privacy Statement for details.

Third-party services

The map uses the following services:

  • Leaflet.js - an open-source mapping library
  • OpenStreetMap - open map tiles. OpenStreetMap's own privacy policy applies to tile requests

Service directory data

The service listings on this map contain only publicly available information about organisations and services, including names, addresses, phone numbers, and opening hours. This information is sourced from publicly available directories and maintained in partnership with Parish Nursing Dundee.

If you represent a service listed on this map and would like to request a correction or removal, please contact us.

Contact

For any other questions, please get in touch.

Changes to this policy

This policy will be updated if the nature of the site changes, for example, if analytics or contact forms are introduced in a future version. The date at the top of this page reflects when it was last revised.

About

Created as part of a project to improve access to recovery services across Dundee and the wider Tay Cities region, developed in partnership with Parish Nursing Dundee.
